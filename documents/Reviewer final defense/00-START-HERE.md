# CPAce Final Defense — Reviewer Pack
**Defense date: October 27, 2026**

This folder is your review kit. Everything in it was pulled straight from the actual
CPAce codebase and from your Chapter 4-5 manuscript draft — not generic thesis
boilerplate. Where a number or rule is cited, it is a real threshold, formula, or file
in the system, not an estimate.

## How to use this pack

Read in this order, budgeting roughly one pass today/tomorrow and a final skim the
night before:

1. **01 – Weakness Detection & Spaced Repetition** — your core contribution. Know this
   cold; it's almost certainly the first thing a panelist probes.
2. **02 – System Walkthrough by Module** — the full feature tour, organized the way a
   panel will think about it: Student → Faculty → Program Chair/Super Admin.
3. **03 – Pilot Testing Results** — your actual Chapter 4-5 numbers, with the exact
   wording you should use (and one important correction about what kind of study this
   was — see the callout box).
4. **04 – Mock Exam Rules & Proctoring** — the most rule-dense module; read this one
   slowly.
5. **05 – Likely Panel Questions & Answers** — rehearsed answers to the questions this
   kind of system almost always draws, written from what the code actually does.

## The one-sentence pitch

> CPAce is a web-based board-exam review platform for BatStateU TNEU ARASOF-Nasugbu
> BSA students that automatically detects which CPALE topics a student is weak in
> (accuracy below 60% over at least 5 attempts, or 3 wrong answers in a row) and
> schedules spaced-repetition review of exactly those topics using the SM-2 algorithm —
> on top of practice quizzes, faculty-run class quizzes, proctored mock board exams,
> and full chair/faculty administration of the curriculum, question bank, and
> performance analytics.

## Ground rule for the defense

If a panelist asks something this pack doesn't cover, say so honestly and offer to
check — do **not** improvise a number. Every figure in `03-Pilot-Testing-Results.md`
is exact; don't round them differently on the day, and don't describe the evaluation
as a "survey" or "questionnaire" — it explicitly was not one (see that file for why
this matters).
